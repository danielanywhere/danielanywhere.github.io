      Remarks

      If a static filename with no patterns is given, the output name will include that name with a dash and numeric suffix, as in 'OutputFilename-0001.png'.

      Because curly braces are reserved for real time variables, keyword patterns are specified in square braces, as in 'BaseName-[Patterns].png', where multiple pattern sections can be specified in a single filename template, as in 'BaseName-[yyyyMMdd]-[Index:4].png'. The following patterns are recognized.

      • '-' - Literal dash.
      • '_' - Literal underline.
      • '.' - Literal period.
      • '~' - Literal tilde.
      • Index - Index of the output file with no padding.
      • Index:n - Index of the output file within the collection, left-padded with 'n' zeros.
      • AP - Single upper case 'A' or 'P' meridiem.
      • AMPM - Double upper case 'AM' or 'PM' meridiem.
      • ap - Single lower case 'a' or 'p' meridiem.
      • ampm - Double lower case 'am' or 'pm' meridiem.
      • d - Day of month with no padding.
      • dd - Two digit day of month.
      • f:n - Fraction of a second padded to 'n' places.
      • H - 24-hour base hour number with no padding.
      • HH - Two digit base hour number.
      • h - 12-hour base hour number with no padding.
      • hh - Two digit 12-hour base hour number.
      • M - Month number with no padding.
      • MM - Two digit month.
      • m - Minute with no padding.
      • mm - Two digit minute.
      • s - Seconds with no padding.
      • ss - Two digit seconds.
      • yy - Two digit year.
      • yyyy - Four digit year.
